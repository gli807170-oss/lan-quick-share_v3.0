# 局域网文件传输

一个运行在 `0.0.0.0:9988` 的轻量文件分享站点，同一局域网内的手机、电脑可以直接访问上传和下载文件。

## 启动

```bash
cd lan-file-share
npm install
npm start
```

启动后控制台会打印本机 IP 地址，例如：

```
http://192.168.1.5:9988
```

同一网络下的设备访问该地址即可。

## 功能

- 拖拽或多选文件上传
- 上传进度显示
- 文件列表、搜索、下载、删除
- 一键复制下载链接
- 单文件默认上限 500MB

## 配置

```bash
PORT=9988
HOST=0.0.0.0
MAX_FILE_SIZE=524288000
```

上传的文件保存在 `uploads/` 目录。
